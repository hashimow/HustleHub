# Hustle Hub

Hustle Hub is a React web application that helps learners discover mentors, books, and useful learning resources.

## Project Goal

The goal of this project is to build a clean frontend application that can later grow into a full-stack platform with a Flask backend, authentication, favorites, and user profiles.

## Current Features

- React application created with Vite
- React Router setup
- Shared layout structure
- Navbar with active route styling
- Pages folder
- Components folder
- Services folder
- Assets folder
- Global CSS styling

## Pages

- Home
- Mentors
- Books
- Favorites
- Login
- Sign Up

## Tech Stack

- React
- Vite
- React Router
- CSS
